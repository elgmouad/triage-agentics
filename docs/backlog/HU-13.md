## Historia de usuario

**Como** desarrollador, **quiero** que cada push y cada Pull Request compilen y ejecuten los tests automáticamente, **para** detectar errores antes de integrarlos en `main`.

> Historia provisional: se detallará cuando se publique el enunciado de este hito.

## Contexto

- **Hito:** Hito 2 — Integración continua (CI)

## Criterios de aceptación

- [ ] Un workflow de GitHub Actions compila y prueba cada servicio en cada push y Pull Request.
- [ ] Una Pull Request con tests en rojo no puede fusionarse en `main`.
- [ ] Las imágenes Docker se construyen en la CI.
- [ ] El README muestra el estado de la CI con un *badge*.

## Tareas técnicas

- [ ] Workflow de GitHub Actions
- [ ] Caché de dependencias Maven
- [ ] Regla de protección de la rama `main`
- [ ] *Badge* de estado en el README

## Definición de hecho

- [ ] Todos los criterios de aceptación se cumplen
- [ ] Código integrado en `main` mediante Pull Request
- [ ] La integración continua (CI) pasa en verde
