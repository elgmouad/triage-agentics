## Historia de usuario

**Como** desarrollador, **quiero** levantar todo el sistema en local con un solo comando, **para** probar la aplicación completa en un entorno reproducible.

> Historia provisional: se detallará cuando se publique el enunciado de este hito.

## Contexto

- **Hito:** Hito 2 — Empaquetado Cloud Native y entorno local

## Criterios de aceptación

- [ ] Cada servicio tiene un `Dockerfile` multi-etapa que genera una imagen ligera que se ejecuta con un usuario no root.
- [ ] `docker compose up` arranca los 8 componentes en el orden correcto gracias a *health checks*.
- [ ] PostgreSQL y los modelos de Ollama usan volúmenes persistentes.
- [ ] Solo el puerto de `api-gateway` se publica en la máquina anfitriona.
- [ ] Las variables sensibles se leen de un archivo `.env` (plantilla `.env.example`).

## Tareas técnicas

- [ ] `Dockerfile` por servicio
- [ ] Archivo `compose.yaml`
- [ ] *Health checks* con Actuator
- [ ] Documentación de arranque en el README

## Definición de hecho

- [ ] Todos los criterios de aceptación se cumplen
- [ ] Código integrado en `main` mediante Pull Request
