## Historia de usuario

**Como** operador, **quiero** que cada integración en `main` se despliegue automáticamente y de forma segura, **para** entregar cambios sin pasos manuales ni exposición de credenciales.

> Historia provisional: se detallará cuando se publique el enunciado de este hito.

## Contexto

- **Hito:** Hito 4 — Despliegue continuo (CD), reconciliación automatizada y seguridad

## Criterios de aceptación

- [ ] Un pipeline de CD despliega automáticamente cada versión integrada en `main`.
- [ ] El estado deseado del despliegue está en Git y se reconcilia automáticamente.
- [ ] Los secretos se gestionan con un gestor de secretos, no en variables en claro.
- [ ] Las rutas `/internal/**` no son accesibles desde el exterior (comprobado con un test).
- [ ] Las dependencias y las imágenes se analizan en busca de vulnerabilidades.

## Tareas técnicas
